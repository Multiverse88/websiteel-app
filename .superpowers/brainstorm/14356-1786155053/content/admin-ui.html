Bagaimana tampilan Tracking Project ini untuk tim Admin?

Pilih pendekatan visual yang paling cocok untuk alur kerja operasional tim Anda saat mengupdate status project klien.

A

Timeline / Milestone (Langkah per Langkah)

Daftar tahapan baku (misal: "Dokumen Diterima", "Proses Notaris", "SK Kemenkumham Terbit"). Admin tinggal menceklis/mengisi tanggal selesai tiap tahap. Sangat terstruktur.

B

Kanban Board (Papan Geser)

Kolom seperti Trello ("To Do", "In Progress", "Selesai"). Kartu proyek klien digeser dari kiri ke kanan. Cocok jika tim ingin melihat keseluruhan proyek secara bersamaan.

C

Simple Status & Persentase

Hanya mengubah satu dropdown status utama (misal: "Proses") dan menginput angka persentase (50%). Sangat sederhana dan cepat, namun kurang detail.
